# BlackboardDismiss Privacy Policy

Last updated: August 3, 2026

BlackboardDismiss is a browser extension developed by JonLuca DeCaro. It dismisses Blackboard notification elements when the user clicks the extension's toolbar button.

## Data handling

On an explicit toolbar click, BlackboardDismiss runs locally in the active tab and its frames, finds the page's existing dismissal controls, and activates them. It does not read or retain notification text for any other purpose.

BlackboardDismiss does not collect, upload, store, sell, or share personal information, Blackboard account data, course information, grades, messages, browsing history, or page content. It makes no external network requests and uses no analytics or advertising services.

## Permissions

- `activeTab` limits access to the tab on which the user invokes the extension.
- `scripting` allows the dismissal function to run in that tab and its embedded frames.

These permissions are used only for the user-requested dismissal action.

## Retention and user control

The extension retains no user data. Removing it ends its access immediately.

## Changes and contact

Material changes to this policy will be reflected in this document and its updated date. Questions may be sent to [chrome@jonlu.ca](mailto:chrome@jonlu.ca).
